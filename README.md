Подготовка репозитория 

Создайте на GitHub новый пустой публичный репозиторий с названием bioinformatics_hw (или названием на ваш выбор).
Клонируйте этот репозиторий к себе на компьютер (в вашу домашнюю директорию Linux).
Перейдите в папку клонированного репозитория.
Создайте файл README.md с кратким описанием задания и вашей фамилией. Можете хоть скопировать это дз)
Сделайте первый коммит с сообщением Init и отправьте (push) его на GitHub.

Работа с директориями и файлами

Одной командой создайте вложенную структуру папок внутри вашего репозитория: linux_task/data/raw/
Перейдите в папку raw.
Создайте три пустых файла: sample1.tsv, sample2.tsv, sample3.tsv.
Запишите в файл sample1.tsv строку: GeneID\tExpression_Value (где \t — это символ табуляции).
Выведите содержимое файла sample1.tsv на экран.
Создайте коммит с сообщением Create raw data structure.

Перенаправление потоков и поиск

В этой же папке (linux_task/data/raw/) создайте файл sequencing_summary.txt со следующим содержимым (используйте echo или cat):
- run_id: RUN001
- date: 2026-02-18
- sample: sample1
- platform: Illumina
- read_length: 150
- total_reads: 1024
- sample: sample2
- total_reads: 2048
- sample: sample3
- total_reads: 4096

Найдите в файле sequencing_summary.txt все строки, содержащие слово sample, и сохраните их в новый файл samples_list.txt.
Подсчитайте количество таких строк (используя wc -l) и допишите это число в конец файла samples_list.txt в виде Total samples found: <число>.
Выведите на экран последние 5 строк файла samples_list.txt, чтобы убедиться, что число дописалось правильно.
Создайте коммит с сообщением Add sample list and count.

Git: Восстановление и отмена 

Создайте новую ветку git-practice и переключитесь на неё.
Создайте файл important_note.txt и запишите в него "This is very important data.".
Добавьте файл в отслеживание и сделайте коммит.
Удалите файл important_note.txt из рабочей директории (командой rm).
Убедитесь, что файл исчез, и проверьте статус Git (git status). 
Восстановите удаленный файл из последнего коммита с помощью Git.
Создайте в корне репозитория файл git_command.txt, в который запишите команду, с помощью которой вы восстановили файл.
Создайте коммит с сообщением Restore deleted file.
